# AI-Engineering

## Engineering Decisions

---

## DEC-0001

### Title

Engineering MCP is the primary objective.

### Status

ACCEPTED

### Decision

The first implementation of AI-Engineering is the Engineering MCP Server.

All initial development focuses on delivering a minimal but production-oriented MCP capable of supporting engineering workflows.

---

## DEC-0002

### Title

Reference Project

### Status

ACCEPTED

### Decision

AI-Archive-Server is the official Reference Project.

Engineering practices are validated there before becoming reusable standards.

---

## DEC-0003

### Title

Documentation Before Code

### Status

ACCEPTED

### Decision

No implementation begins until the documentation foundation has been completed and approved.

---

## DEC-0004

### Title

MVP Strategy

### Status

ACCEPTED

### Decision

The first Engineering MCP release focuses exclusively on:

* Workspace Tools
* Git Tools
* Python Development Tools

Additional capabilities are introduced only after the MVP is operational.

## DEC-0006

### Title

Self-Hosting Vision

### Status

ACCEPTED

### Decision
